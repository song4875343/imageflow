# 图片编辑 + 空间设计（EROOM）

两个项目拼接的桌面应用：图片编辑（深色/浅色主题）+ 空间设计 3D 建模。

## 图片图层操作

- `Ctrl+J` 复制当前图片图层，新图层自动成为当前图层并开启「微调」移动。
- `Shift+点击` 缩略图多选图层，多选状态出现「合并」按钮，可将选中的非主图图片图层合并为一张新图层。
- 缩略图自动裁掉透明边距，让非透明内容充满卡片。
- 选中非主图图片图层时，画布上沿非透明轮廓向外 20px 显示亮蓝 1px 虚线边界；进入图片编辑/蒙版/补丁画笔时隐藏，退出后恢复。
- 蓝色边界为屏幕恒定 1px 虚线（线宽/虚线间隔按缩放换算）。
- 「调整」按钮：把图层裁到非透明内容后生成可拖动/缩放/旋转的编辑框，框下边缘两侧为 ⇄/⇅ 镜像按钮；再点「调整」退出并重新锁定。

## 目录结构

- `image_eidt/` — 图片编辑应用（app.py / index.html / image_edit.py）
- `roomspace/` — 空间设计（EROOM）3D 应用源码，启动时自动打包嵌入
- `webridge/` — WebBridge 浏览器生图桥接（上传 / 发送 / 全尺寸下载）
- `启动图片微调.bat` — 启动入口（放在项目根目录）

## 启动

双击根目录的 `启动图片微调.bat`，或在根目录运行：

```powershell
uv run python image_eidt/app.py
```

首次运行会自动创建虚拟环境并安装依赖（需联网，three.js / fabric.js 从 CDN 加载）。
图片编辑的模型配置保存在 `image_eidt/image_models.json`；空间设计的模型保存在 `roomspace/public/models.json`。
