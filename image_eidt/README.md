# 图片编辑 + 空间设计（EROOM）

两个项目拼接的桌面应用：图片编辑（深色/浅色主题）+ 空间设计 3D 建模。

## 图片图层操作

- `Ctrl+J` 复制当前图片图层，新图层自动成为当前图层并开启「微调」移动。
- `Shift+点击` 缩略图多选图层，多选状态出现「合并」按钮，可将选中的图片图层合并为一张新图层。
- 主图不再禁止修改：可与其他图层一起多选、合并、删除，可开启「微调」拖动/缩放/方向键微移，可用「调整」编辑框缩放/旋转/镜像，也可作为补丁/蒙板的取图源；主图仅作为画布尺寸基准与底层背景带存在。
- 缩略图自动裁掉透明边距，让非透明内容充满卡片。
- 选中图片图层时，画布上沿非透明轮廓向外 20px 显示亮蓝 1px 虚线边界；进入图片编辑/蒙版/补丁画笔时隐藏，退出后恢复。
- 蓝色边界为屏幕恒定 1px 虚线（线宽/虚线间隔按缩放换算）。
- 「调整」按钮：把图层裁到非透明内容后生成可拖动/缩放/旋转的编辑框，框下边缘两侧为 ⇄/⇅ 镜像按钮，上方旋转把手左右各有一个 ↺/↻ 90° 旋转按钮；工具条「旋转」文本框与旋转把手双向绑定（拖动把手实时显示角度，输入角度直接旋转）；再点「调整」退出并重新锁定。
- 颜色选区（魔棒）：图片编辑为「按颜色建立选区」，默认自动判断图片层中的文字颜色，按 PS 默认容差 32 建立选区并适度外扩；可调容差或点吸管在图上重新取色。算法独立在 `image_eidt/color_selection.js`。
- 色彩平衡：图片编辑工具条中「调整（缩放/旋转）」按钮右侧的「色彩平衡」，用青-红 / 洋红-绿 / 黄-蓝三条色轴（含数值框）调整；拖动色轴时图层实时预览效果，点「应用」确定并烘焙进图层，点「取消」还原。若当前处于颜色/套索选区，则只作用于选区内容，否则作用于整个图层。
- 颜色匹配（复刻 PS「匹配颜色」）：选中图片图层后进入「图片编辑」，点「颜色匹配」按钮，再点一个图片缩略图作为参考图层；当前图层会按参考图层在 CIE L*a*b* 空间的均值/标准差实时匹配（Reinhard 颜色迁移算法），可调亮度 / 色彩强度 / 渐隐或勾选「中和参考色偏」，效果满意后点「应用」确定、点「取消」还原。算法独立在 `image_eidt/color_match.js`。
- 打开参考图（加载其他图）时与主图使用同一标准：左上角 (0,0) 对齐、保持原图原始像素尺寸（不拉伸不缩放），便于与主图/蒙版/选区同坐标系对齐取用；需要缩放时用「调整」编辑框。
- 透视裁剪：选中图片图层后点「透视裁剪」，四个角点可任意拖动（工作区会随图层范围扩展，支持覆盖旋转后伸出画布的内容），点「应用拉正」按四边形生成新图层；结果按图层原始分辨率采样，减少拉正后发糊。四边形内叠加与 PS 透视裁剪一致的预估网格：按单位正方形到四边形的投影变换（单应矩阵）把规则网格反投影回来，网格线随透视收敛，直观预示拉正后等距矩形的效果；工具条「网格」滑块可调每轴格数（1~12，1 为关闭网格）。

## 目录结构

- `image_eidt/` — 图片编辑应用（app.py / index.html / image_edit.py / color_selection.js / color_match.js）
- `roomspace/` — 空间设计（EROOM）3D 应用源码，启动时自动打包嵌入
- `webridge/` — WebBridge 浏览器生图桥接（上传 / 发送 / 全尺寸下载）
- `启动图片微调.bat` — 启动入口（放在项目根目录）

## 启动

双击根目录的 `启动图片微调.bat`，或在根目录运行：

```powershell
uv run python image_eidt/app.py
```

首次运行会自动创建虚拟环境并安装依赖（需联网，three.js / fabric.js 从 CDN 加载）。
图片编辑的模型配置保存在 `image_eidt/image_models.json`；空间设计的模型保存在 `roomspace/public/models.json`。
